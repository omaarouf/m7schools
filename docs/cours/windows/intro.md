# Administration Windows

**Administration des serveurs Windows Server 2019 / 2022.**

Ce module couvre l'installation, la configuration et la gestion des serveurs Windows dans un environnement professionnel. Toutes les commandes et configurations sont presentees pour **Windows Server 2019** et **Windows Server 2022**.

:::info Avertissement

Ce contenu est cree et maintenu par moi. Il peut contenir des erreurs ou necessiter des ameliorations. Il est fortement recommande de **tester toutes les configurations sur une machine virtuelle reelle** avant de les appliquer en production.

:::

---

## Objectifs du module

- Maitriser les commandes de base PowerShell
- Installer et configurer Active Directory (AD DS)
- Configurer les services DNS et DHCP sous Windows Server
- Gerer les politiques de groupe (GPO)
- Administrer les services de fichiers et le partage reseau
- Deployer et configurer IIS (serveur web)
- Mettre en place des strategies de sauvegarde et recuperation

**1. Lire le cours** - comprendre les concepts et les commandes

**4. Passer a la lecon suivante**

:::

:::tip Conseil pratique

Toutes les demonstrations utilisent **PowerShell** en mode administrateur. Pour ouvrir PowerShell en tant qu'administrateur : clic droit sur l'icone PowerShell → **Executer en tant qu'administrateur**.
